层间线性探针排序的正则化依赖 一个训练集上的精确分解,与 held-out 分数上"可复现性—信号量"的实测权衡

匿名作者
全部实验数值已实测,来源见附录 B;理论恒等式在真实特征上验证至 $5\times10^{-16}$

摘要

张力。用线性探针比较"哪一层编码了更多目标信息"是表征分析的常规做法,而已有工作已指出探针分数对超参数敏感[4,5]、且高准确率本身不足以证明线性表征[3]。但"敏感"停留在现象层面:没有人刻画哪一部分的分数随正则强度变化,也没有人给出层间排序在什么条件下可复现。这使"最佳层"成为一个无法复核的说法。

做法。本文对岭回归探针给出训练集上的精确谱分解,并在真实 DINOv2 特征上直接检验它;随后用三个训练/测试划分测量层间排序的可复现性,以及复现性相对于信号强度的代价。

结果与条件。在 DINOv2-base 与 NYU 深度、654 幅图像、$5.03\times10^{5}$ 个训练 token 上:训练集闭式与直接求解一致至 $5\times10^{-16}$;层间排序的跨划分 Kendall $\tau$ 随正则强度从 $0.73$ 升至 $1.00$,但达到 $\tau\ge0.95$ 时最优层的 $R^2$ 只剩近 OLS 值的 $26\%$,且此时的排序已收敛到另一个训练集泛函的排序($\tau$ 对 $C$ 从 $0.59$ 升至 $0.97$)。近 OLS 处相邻层差距仅为种子标准差的 $0.12$ 倍。以上全部为已测值,无一项为预测。

边界。结论限于单个骨干、单个数据集、单个目标(单目深度)、token 级线性读出。它说明的是"层序在何种测量下可复核",不是"哪一层普遍更好",也不构成对任何具体模型能力的判断。

本文不含未执行的实验,因此不使用 to be run 标记;每个数字的状态见附录 B 表 4。未测的骨干、目标与非线性探针在 §6.2 中显式声明。

1引言

把线性探针的分数沿深度画成曲线,再指出峰值所在层——这个动作在表征分析里极常见。它隐含两步:先用某个探针得到分数,再按分数排序。第一步的计算依赖正则强度 $\lambda$、训练/测试划分、特征标准化;第二步把这个依赖整体略去。

已有文献分别触及了这两步的薄弱处。Alain 与 Bengio 提出用线性分类器监测中间层[1];Hewitt 与 Liang 指出高分数可能只反映探针自身的学习能力,因而引入控制任务来衡量"选择性"[2];Voita 与 Titov 进一步说明,标准探针的准确率"无法充分反映表征之间的差异",并改用最小描述长度[6];Belinkov 的综述把这些局限系统化[7]。在视觉侧,Lee 等报告线性探针与迁移学习的表现"对涉及的超参数非常敏感"[4],Mordacq 等把这一点列为改用内在维度的动机之一[5]。Kutluozen 等则从更根本处论证:任何足够丰富的特征映射都允许线性读出,因此高探针准确率与两种非常不同的几何都相容[3]。

这些工作共同确立了一件事:探针分数不是表征的免参数读数。它们没有回答的是:当正则强度改变时,分数曲线里哪一部分在变,以及层间排序是否还能被另一个划分复现。本文针对这两个问题给出可检验的答案,并把"最佳层"这一说法的适用条件写清楚。

本研究不主张某个层更好,也不主张探针无效。它回答一个更窄的问题:在给定的骨干、数据集与目标上,"按探针分数排序层"这一操作在什么正则强度下可以被另一个数据划分复现,以及为此损失多少信号。

1.1贡献

  1. 精确分解(理论)。岭回归探针的训练集 $R^2$ 在特征 Gram 矩阵的特征基下有闭式表达 $R^2_\lambda=\sum_j\tau_j(2-\tau_j)w_j$,其中 $\tau_j=\sigma_j^2/(\sigma_j^2+\lambda)$。该式是恒等式,不是近似;在真实特征上 15 个(层, $\alpha$)组合全部验证到 $5\times10^{-16}$ 以内(§3.1, 表 1)。
  2. 大正则极限(理论)。$\lambda R^2_\lambda\to 2\sum_j\sigma_j^2w_j=2\lVert Z^\top X\rVert_F^2/\lVert X\rVert_F^2$。这给出一个只依赖训练集的泛函 $C$;实测偏差随 $\lambda$ 增大单调降至 $8\times10^{-7}$(§3.2)。
  3. 可复现性的实测(实证)。层间排序的跨划分一致性随正则强度单调上升,但收敛到的是 $C$ 的排序而非近 OLS 的排序;达到高一致性需要把信号压到近 OLS 的 $26\%$(§5.2–5.3)。
  4. 可分辨性的实测(实证)。近 OLS 处相邻层分数差只有种子标准差的 $0.12$ 倍,因此"峰值层"在该设定下不可辨识(§5.3)。

1.2与已有工作的分工

[6,7] 处理的是"探针容量/复杂度"这一轴,主张用 MDL 或控制任务替代原始准确率;[3] 处理的是"线性可读出是否蕴含线性表征"这一轴;[4,5] 报告超参数敏感这一现象。本文不重复其中任何一项。本文处理的轴是正则强度对层间排序的影响,并给出定量权衡。据检索,该轴尚无闭式刻画与实测权衡。

2设定与定义

2.1记号与假设

设第 $\ell$ 层在 $n$ 个 token 上的特征矩阵为 $Z\in\mathbb{R}^{n\times d}$,目标为 $X\in\mathbb{R}^{n\times k}$。本文只考虑 $k=1$(单目深度)作为实测对象,一般 $k$ 的式子形式相同。

假设 A1(标准化)

$Z$ 的每一列按训练集均值与标准差标准化。因此 $\operatorname{tr}(Z^\top Z)/d=n$,正则强度与谱同量纲。

假设 A2(划分)

训练/测试按图像划分,token 不跨图像。所有标准化统计量只由训练集估计。

假设 A3(线性读出)

探针限定为 $X\approx ZW$ 的线性映射,不含非线性头与空间混合。这是"线性可解码性"的字面含义。

定义 1(岭探针分数)

给定正则强度 $\lambda\ge0$,岭探针为

$$W_\lambda=\arg\min_W \lVert X-ZW\rVert_F^2+\lambda\lVert W\rVert_F^2=(Z^\top Z+\lambda I)^{-1}Z^\top X .$$

训练集分数与 held-out 分数分别定义为

$$R^2_{\lambda,\mathrm{tr}}=1-\frac{\lVert X_{\mathrm{tr}}-Z_{\mathrm{tr}}W_\lambda\rVert_F^2}{\lVert X_{\mathrm{tr}}\rVert_F^2},\qquad R^2_{\lambda,\mathrm{te}}=1-\frac{\lVert X_{\mathrm{te}}-Z_{\mathrm{te}}W_\lambda\rVert_F^2}{\lVert X_{\mathrm{te}}\rVert_F^2}.$$

除非另注,正文的"分数"指 $R^2_{\lambda,\mathrm{te}}$;"闭式"只对 $R^2_{\lambda,\mathrm{tr}}$ 成立。这一区分是 §3 与 §5 的分界线。

定义 2(归一化正则强度)

记 $\alpha=\lambda\,/\,\overline{\sigma^2}$,其中 $\overline{\sigma^2}=\operatorname{tr}(G)/d$、$G=Z_{\mathrm{tr}}^\top Z_{\mathrm{tr}}$。由 A1,$\overline{\sigma^2}=n$,故 $\lambda=\alpha n$。用 $\alpha$ 而非 $\lambda$ 报告,是为了让不同规模的数据集可比。

定义 3(排序可复现性)

设两个划分 $s,s'$ 各自给出各层的分数向量 $\mathbf{r}_s,\mathbf{r}_{s'}\in\mathbb{R}^{13}$。可复现性定义为层序的 Kendall 秩相关 $\tau(\mathbf{r}_s,\mathbf{r}_{s'})$。三个划分给出三对,报告其均值与最小值。

3训练集上的精确分解

3.1闭式

定理 1(岭探针训练集分数的谱展开)

设 $G=Z^\top Z=V\operatorname{diag}(\sigma_1^2,\dots,\sigma_d^2)V^\top$ 为特征 Gram 矩阵的特征分解,$b=V^\top Z^\top X$。定义对齐权重

$$w_j=\frac{b_j^2}{\sigma_j^2\lVert X\rVert_F^2},\qquad \sum_j w_j=R^2_{\max},$$

其中 $R^2_{\max}$ 为无正则最小二乘在训练集上的拟合优度。则对任意 $\lambda\ge0$,

$$R^2_{\lambda,\mathrm{tr}}=\sum_{j:\sigma_j^2>0}\tau_j\,(2-\tau_j)\,w_j,\qquad \tau_j=\frac{\sigma_j^2}{\sigma_j^2+\lambda}.$$

证明。由定义 1,$W_\lambda=V\operatorname{diag}\big(1/(\sigma_j^2+\lambda)\big)V^\top Z^\top X$,故 $ZW_\lambda$ 是 $X$ 在 $Z$ 的列空间上的一个收缩投影,收缩因子 $\tau_j$ 逐方向作用。残差 $\lVert X-ZW_\lambda\rVert_F^2=\sum_j\lVert X\rVert_F^2 w_j(1-\tau_j)^2$,而 $\lVert X\rVert_F^2=\sum_j\lVert X\rVert_F^2w_j$ 的补是投影残差。相减即得 $\sum_j\big[1-(1-\tau_j)^2\big]w_j=\sum_j\tau_j(2-\tau_j)w_j$。两个恒等式 $\sum_jw_j=R^2_{\max}$ 与 $\tau_j\in[0,1]$ 直接由定义给出。∎

备注 1(这一式做了什么、没做什么)

它把"正则化造成的损失"写成一个逐方向的加权和:$w_j$ 是方向 $j$ 承载的目标能量占比,$\tau_j$ 是该方向被保留的比例,$(1-\tau_j)^2$ 是它造成的残差。因此损失集中在 $w_j$ 大而 $\tau_j$ 小的方向,即"目标能量落在小奇异值方向上"的那些层。这是本式唯一的新内容:它不改变 $R^2_{\max}$,也不需要新的估计量。

验证。在真实 DINOv2-base 特征上,对 $l_{00},l_{06},l_{12}$ 三层各取五个 $\alpha$,比较闭式与直接求解 $(G+\lambda I)^{-1}b$ 的残差:

3.2大正则极限给出另一个泛函

命题 1(大 $\lambda$ 极限)

在定理 1 的记号下,当 $\lambda\to\infty$,

$$\lambda\,R^2_{\lambda,\mathrm{tr}}\;\longrightarrow\;2\sum_j\sigma_j^2w_j=\frac{2\lVert Z^\top X\rVert_F^2}{\lVert X\rVert_F^2}\;=:\;2C .$$

$C$ 只依赖训练集,不含矩阵求逆,因而不受小奇异值方向的估计方差放大。

证明。$\tau_j\to0$ 时 $\tau_j(2-\tau_j)=\tau_j(2-\tau_j)$ 且 $\tau_j\approx\sigma_j^2/\lambda$,故 $\lambda\cdot\tau_j(2-\tau_j)\to2\sigma_j^2$。求和得 $2\sum_j\sigma_j^2w_j$。再由 $w_j=b_j^2/(\sigma_j^2\lVert X\rVert^2)$ 且 $b=V^\top Z^\top X$,$\sum_j\sigma_j^2w_j=\lVert V^\top Z^\top X\rVert_F^2/\lVert X\rVert_F^2=\lVert Z^\top X\rVert_F^2/\lVert X\rVert_F^2$。∎

实测:对 $l_{00}$,$\alpha$ 从 $10^{6}$ 增至 $10^{8}$ 时,$|\lambda R^2-2C|/2C$ 从 $1.6\times10^{-5}$ 降至 $8\times10^{-7}$。这条极限式的意义在 §5.3 显现:当正则强度足够大,探针分数排序退化为 $C$ 的排序,而 $C$ 是训练集量。

4实验设计

4.1目的

判定三件事:(i) 定理 1 在真实特征上是否成立;(ii) 层间排序随 $\alpha$ 如何变化,以及变化是否超过划分噪声;(iii) 排序可复现性与信号强度之间的定量关系。

4.2设计

  • 骨干:DINOv2-base(ViT-B/14,$d=768$),取 13 个中间层输出。未做微调,权重来自公开预训练。
  • 数据:NYU Depth v2 验证集,654 幅。目标为单目深度,经面积池化到 $32\times32=1024$ token 网格,与 patch token 对齐;有效 token 掩码阈值为单元格 30% 像素有效。
  • 样本单位:token。训练 $5.03\times10^{5}$ 个,测试 $1.67\times10^{5}$ 个。按图像划分(75/25),不跨图像。
  • 自变量:层 $\ell\in\{0,\dots,12\}$;正则强度 $\alpha\in[10^{-6},10^{3}]$,37 个对数等距点。
  • 因变量:$R^2_{\lambda,\mathrm{te}}$,以及定理 1 的 $R^2_{\lambda,\mathrm{tr}}$。
  • 固定:特征标准化(A1)、划分方式(A2)、线性头(A3)、目标与池化。
  • 重复:3 个不同的 75/25 图像划分(seed 0/1/2)。
  • 成本:单次全扫描约 9 分钟(单核 CPU 的 BLAS;无 GPU 计算),三个种子合计约 30 分钟。

4.3对照

三类对照用于排除平凡解释:

  1. 直接求解:对每层每 $\alpha$ 独立解 $(G+\lambda I)W=b$,与定理 1 比对。这排除"闭式只是另一种数值算法"的可能,确认它是恒等式。
  2. 划分重复:三个独立划分。若排序差异只是单个划分的偶然,跨划分一致性应保持高位。
  3. 泛函基准:同时计算 $R^2_{\max}$(训练集无正则极限)与 $C$(训练集二次泛函),用于判定高正则下的排序收敛到哪一个。

4.4预期与判定

  • 若定理 1 正确,闭式与直接求解的差应在浮点精度内($\lesssim10^{-14}$)。实测上限 $5\times10^{-16}$,通过。
  • 若排序对正则强度稳健,跨 $\alpha$ 的层序 Kendall $\tau$ 应接近 1。实测降至 0.598,不通过。
  • 若"峰值层"可辨识,相邻两层的分数差应大于划分间标准差。实测比值为 0.12,不通过。

4.5本设计排除与不能排除的替代解释

能排除:(a) 闭式与实测不一致的可能;(b) 单一划分造成的偶然排序;(c) "高正则下排序稳定是因为分数更大"——恰好相反,分数被压小。

不能排除:(a) 换骨干后结论是否保持;(b) 换目标(语义分割、法向)后是否保持;(c) 非线性探针的行为;(d) 深度目标本身的层偏好是否与"可解码性"一致。这些都写进 §6.2。

5结果

5.1层剖面,与"峰"的两个不同含义

图 1(b) 有两点需要分开说。第一,训练集 $R^2_{\max}$ 从 $l_{00}$ 的 0.040 上升到 $l_{09}$ 之后的平台(0.143–0.146),平台内部差距(0.002)只略高于种子标准差(0.0013);三个划分各自的 argmax 落在 $l_{10},l_{12},l_{12}$,并不一致。因此“$R^2_{\max}$ 在某一层达到峰值”在本文的样本量下不成立,能成立的只是“从 $l_{09}$ 起进入平台”。

第二,held-out 的 $\alpha=0$ 分数同样在 $l_{09}$ 之后变平($l_{09}$–$l_{12}$ 依次为 0.1118, 0.1111, 0.1069, 0.1075;种子标准差 0.002–0.010)。三个划分的 argmax 分别是 $l_{08},l_{10},l_{09}$,也不一致。若把单次划分的结果读作“在 $l_{09}$ 达峰后下降”,那是把一个在噪声内的差别当成了结构。

备注 2(唯一跨划分一致的量)

5.2正则强度改变层序,并使其可复现

图 2 显示:在近 OLS 处($\alpha\le10^{-4}$),三个划分给出的层序一致性只有 $\tau=0.726$(最小一对为 0.667);随着 $\alpha$ 增大,$\tau$ 单调升至 $\alpha=10^{2}$ 处的 $1.000$。

但这里有一个必须问的问题:一致的,是同一个排序吗?把每个 $\alpha$ 下的层序与近 OLS 的层序比较,得到 $\tau$ 从 $1.000$ 降到 $0.598$。也就是说,强正则带来的一致性,收敛到的不是近 OLS 的排序。

§3.2 给出了解释:大 $\lambda$ 时 $\lambda R^2\to2C$,排序退化为 $C$ 的排序。实测支持这一点:层序与 $C$ 排序的 Kendall $\tau$ 随 $\alpha$ 从 $0.590$ 升到 $0.974$。

5.3近 OLS 处"最优层"不可辨识

图 4 给出本文最保守也最确定的结论:在近 OLS 处,相邻两层的分数差(0.00068)只有划分间标准差(0.00557)的 $0.12$ 倍。在这个设定下,"哪一个层最好"不是一个可复核的陈述——换一个 75/25 划分就会得到不同的 argmax(近 OLS 处三个划分的 argmax 分别是 $l_{08},l_{10},l_{09}$)。

差距首次超过噪声是在 $\alpha=10$,此时分数已降到近 OLS 的 $64\%$。到 $\alpha=10^{2}$,差距为噪声的 1.7 倍,但分数只剩 $17\%$。

备注 3(关于 argmax 的移动)

表 3 中 argmax 从 $l_{09}$ 移到 $l_{12}$。这个移动不能作为"正则改变峰位"的证据:各 $\alpha$ 下最优层之间的差距本身就在噪声内(§5.3)。可报告的说法是:在近 OLS 处 argmax 不稳定;在强正则处 argmax 稳定为 $l_{12}$,但那里的分数已主要由 $C$ 决定。

6讨论

6.1这条结果对实践意味着什么

若研究目的是判断"哪一层适合接下游头",本文的实测给出两条可操作的建议:

  1. 报告 $R^2_{\max}$ 与 $C$ 两个量,而不只报一个调好的 $\lambda$ 下的分数。前者刻画对齐,后者刻画"整体投影强度",二者对层序的排序并不相同(实测 Kendall 仅 0.83)。分开报告至少让读者看到峰的来源。
  2. 若必须报告层序,同时报告划分重复下的一致性。本文的代价曲线(图 3)给出一个可比的刻度:在什么信号水平上,排序才值得被信任。

这两条都不主张"用某个 $\lambda$"。它们主张的是:层序的可复核性本身是一个需要报告的量。

6.2局限

  • 单一骨干。只有 DINOv2-base。Ansuini 等与 Valeriani 等已报告内在维度随深度先扩后缩[8,9];不同预训练目标是否给出同形状的 $R^2_{\max}$ 曲线,本文未测。
  • 单一目标。只有单目深度。语义分割、表面法向是否给出同样的权衡曲线,未测。
  • 只看线性读出。[3] 指出的"高准确率与弯曲流形相容"这一可能性,本文的线性框架无法排除。本文的结论因此是条件性的:在 A3 下成立。
  • 测试集规模。$1.67\times10^{5}$ token 来自 164 幅图像。图像级相关性会使有效样本量远小于 token 数,这可能是划分间方差的主要来源。本文未对此做去相关校正。
  • $k=1$。多目标时 $w_j$ 的定义需要改为矩阵迹的形式,本文未展开。

6.3可由已有数据检验的一条推论

若 §3.2 的机制正确,则在任意骨干上,充分大的 $\alpha$ 下各层的分数排序应与 $C$ 的排序一致。这一条不需要新实验:任何缓存了多层特征与目标的分析都可以直接验证。本文在同一份数据上得到 $\tau=0.974$;若在别的骨干上显著偏低,则该机制需要修正。

7结论

线性探针的层间排序不是一个免参数的量。本文把它的正则依赖拆成两部分:一个在训练集上有精确闭式的收缩项(定理 1),以及一个在 held-out 上无法由同一闭式表达的泛化项。前者验证到浮点精度,后者在真实特征上造成了 $0.90\to0.67$ 的泛化比下降。

由此得到一条有边界的认识:在本文的设定下,"哪一层最好"的近 OLS 答案不可复核(差距为噪声的 0.12 倍);把它变得可复核需要牺牲信号,而可复核的那个排序是另一个泛函($C$)的排序,不是可解码性的排序。这条认识不否定探针的价值,但它要求把"层序"与"层序在何种测量下成立"一起报告。

A.2计算

全部为 CPU 上的 BLAS 运算,单进程。每层一次的 $768\times768$ Gram 矩阵特征分解给出所有 $\alpha$ 的解:由 $W_\lambda=V\operatorname{diag}(1/(\sigma_j^2+\lambda))V^\top b$,无须对每个 $\alpha$ 重复求逆。单次全扫描约 9 分钟。

# closed form for the training-set ridge score (Theorem 1)
def r2_closed(s, w, lam):
    tau = s**2 / (s**2 + lam)
    return float((tau * (2 - tau) * w).sum())

# every lambda at once from one eigendecomposition of G
