逐层线性可解码性的分解 子空间对齐与正则化间隙:以 DINOv3 的深度探针为例

匿名作者
DRAFT · 标注 to be run 处为尚未测量的数值

摘要

冻结视觉编码器的逐层线性探针被广泛用于回答"几何信息在哪一层最可解码",其输出是一条以层为横轴的可解码性曲线。本文指出,该曲线是两个性质不同的量之差:其一是最佳线性可解码性,即在无正则化、总体最优的意义上,目标因子能被特征线性解释的比例;其二是正则化间隙,即有限样本下岭回归因收缩而损失的精度。定理 1 证明前者只依赖目标因子列空间与特征列空间之间的主角,因而对特征侧与因子侧的任意可逆线性变换都不变;定理 2 给出后者的谱展开,证明它只依赖奇异值谱与正则化强度,而奇异值谱可被任意重参数化改变。推论 2.1 由此得到总误差的精确分解:投影残差与收缩偏差两项可加且互不干扰。定理 3 给出归因判据:若最佳线性可解码性在层间变化可忽略,而观测曲线存在显著峰,则峰必须归于正则化间隙。

据此我们设计了一个判别性检验:单骨干、单数据集、一次特征缓存、一次奇异值分解、十三次岭回归,可在数小时内完成。该检验的判据是——在随机可逆重参数化下,最佳线性可解码性不变而观测曲线移动。本文提出两项待验预测:子空间对齐在层间的变化小于观测峰高的三分之一;同一重参数化下,前者不动而后者移动。所有经验数值标 to be run;若预测被推翻,则峰应归因于内容差异,本文的分解框架不适用。

1引言

1.1 问题的背景 自 Alain 与 Bengio 以来,以线性探针衡量中间层表征的线性可及性已成为标准做法[1]。在三维几何属性研究中,该做法被用来定位"深度在 DINO 的第几层最可解码"[3,5],并进一步支撑下游的层选择与多层融合策略[4]。这一用法隐含一个假定:逐层探针曲线的形状反映表征本身在不同深度的几何信息量。

近两年出现了两条针对该假定的批评路线,但均未正面处理曲线内部的构成。

第一条路线关注测量协议。固定骨干、改变读出头的族、参数化、评分指标与判定阈值后,层位结论会发生移动,趋势类甚至发生翻转。这类工作确立了"结论依赖协议",其局限在于只报告了不稳定性,未给出一个不受协议影响的替代量。

第二条路线关注探针假设类的表达能力。Kutluozen 等[2]指出,线性探针的检验过于宽松:渐近地,任何足够丰富的特征映射(包括随机映射)都允许线性读出,因此高探针准确率与两种非常不同的几何结构相容——真正的线性世界模型,以及"潜在变量线性地位于一个更大弯曲流形内部"的核机器情形。该文提出三项非对称诊断以区分二者:反向预测性、谱集中度与分布外泛化。其中谱集中度(前若干主成分的能量占比)在同一子空间的基旋转下不保持不变,因此其数值依赖所选的参数化。

本文关注的对象与上述两条路线不同。我们不讨论协议是否影响结论,也不讨论探针假设类是否过宽;我们指出,逐层探针曲线本身是两个独立量的差,而这两个量对参数化的敏感性完全不同。

1.2本文的处理

设第 $\ell$ 层的特征矩阵为 $Z_\ell\in\mathbb R^{n\times d}$,目标因子矩阵为 $X\in\mathbb R^{n\times k}$。定义两个量:

$$ \underbrace{R^2_{\max}(\ell)\;=\;1-\frac{\min_{W}\|X-Z_\ell W\|_F^2}{\|X-\bar X\|_F^2}}_{\text{最佳线性可解码性}}\;,\qquad \underbrace{\Delta_\lambda(\ell)\;=\;R^2_{\max}(\ell)-R^2_{\lambda}(\ell)}_{\text{正则化间隙}} $$

其中 $R^2_\lambda$ 是岭回归(强度 $\lambda$)在留出集上的实测值。三点结论:

  1. $R^2_{\max}$ 只依赖两个列空间:$\operatorname{col}(X)$ 与 $\operatorname{col}(Z_\ell)$,因而对 $Z_\ell\mapsto Z_\ell G$($G$ 可逆)与 $X\mapsto XH$($H$ 可逆)均不变(定理 1)。它是唯一可以跨模型、跨层、跨参数化比较的逐层量。
  2. $\Delta_\lambda$ 由奇异值谱与 $\lambda$ 决定。由于奇异值谱可被重参数化任意改变,$\Delta_\lambda$ 不具跨参数化意义(定理 2)。
  3. 因此,若 $R^2_{\max}$ 在层间近乎不变而 $R^2_\lambda$ 存在峰,则峰必须归于 $\Delta_\lambda$(定理 3)。

第 3 点是可证伪的,且检验成本很低:无需枚举协议空间,只需测一次 $R^2_{\max}$,再用一次随机可逆重参数化验证其不变性。

2设定与定义

2.1 记号 第 $\ell$ 层在全部输入上产生特征 $Z_\ell\in\mathbb R^{n\times d}$,目标因子 $X\in\mathbb R^{n\times k}$。$n$ 为用于分析的样本数(下详),$d$ 为特征维度,$k$ 为因子维数。

样本单位的选取。若以整图特征(池化后的 $d$ 维向量)为单位,则 $n$ 等于图像数(如 654),而 $d$ 可达 1024,此时 $n\lt d$,最小二乘解不唯一、$R^2_{\max}\equiv 1$,分解失去意义。因此本文的分析在 token 级进行:$n$ 为全部图像的全部 token 总数(例如 654 张图 × 196 token ≈ 1.28×10⁵),此时 $n\gg d$,回归问题适定。相应地,目标因子须定义在 token 上,例如逐 patch 的深度值。这一点是本文可执行性的前提,也是其主要局限之一(见 §6.2)。

假设。$Z_\ell$ 与 $X$ 均列满秩;$n\gg d\ge k$。秩亏情形见附录 A.1。

2.2最佳线性可解码性

定义 1

给定 $Z\in\mathbb R^{n\times d}$ 与 $X\in\mathbb R^{n\times k}$,定义

$$R^2_{\max}(Z,X)\;=\;1-\frac{\min_{W\in\mathbb R^{d\times k}}\|X-ZW\|_F^2}{\|X-\bar X\|_F^2},$$

其中 $\bar X$ 为按列均值中心化后的矩阵。该量即总体(无正则、无有限样本偏差)意义下的最优线性可解码比例。

由于最小二乘的最优解是 $X$ 在 $\operatorname{col}(Z)$ 上的正交投影,残差 $\min_W\|X-ZW\|_F$ 恰为 $X$ 在 $\operatorname{col}(Z)$ 的正交补上的投影范数。因此 $R^2_{\max}$ 是一个只关于两个子空间的量。

2.3主角与子空间对齐

定义 2(主角)[8, 9]

设 $Q_X\in\mathbb R^{n\times k}$、$Q_Z\in\mathbb R^{n\times r}$ 分别为 $\operatorname{col}(X)$、$\operatorname{col}(Z)$ 的正交基,$r=\operatorname{rank}Z$。两个子空间的主角的余弦定义为

$$\cos\theta_i\;=\;\sigma_i\big(Q_X^\top Q_Z\big),\qquad i=1,\dots,\min(k,r),$$

其中 $\sigma_i(\cdot)$ 表示第 $i$ 个奇异值。称 $\{\cos\theta_i\}$ 为主角余弦谱;$1-\cos\theta_{\min}$ 为最差方向的对齐缺口。

主角余弦谱与 $R^2_{\max}$ 的关系是确定的:后者等于前者平方的加权和,权重由 $X$ 各主方向的方差给出。因此二者携带相同的信息,但主角谱按方向分解,便于逐方向报告。本文在图中使用 $R^2_{\max}$ 便于与实测 $R^2$ 同尺度比较,在表中使用主角谱便于诊断。

2.4正则化间隙

定义 3

设 $R^2_\lambda$ 为岭回归在留出集上的决定系数,则称 $\Delta_\lambda=R^2_{\max}-R^2_\lambda$ 为正则化间隙。它度量的是"由于收缩而未能取到的可解码性"。

3主要结果

3.1 本节的三项结果皆可由 §2 的定义直接得到,不需要新的数学工具。我们逐条陈述并给出证明,因为文献中常用逐层探针曲线而不区分这两个量。

定理 1(最佳线性可解码性的双侧不变性)

设 $Z\in\mathbb R^{n\times d}$、$X\in\mathbb R^{n\times k}$ 均列满秩。对任意可逆矩阵 $G\in\mathbb R^{d\times d}$ 与 $H\in\mathbb R^{k\times k}$,有

$$R^2_{\max}(ZG,\,XH)\;=\;R^2_{\max}(Z,\,X).$$

等价地,主角余弦谱 $\{\cos\theta_i\}$ 对两侧的可逆线性变换均不变。

证明。可逆右乘不改变列空间:$\operatorname{col}(ZG)=\operatorname{col}(Z)$,$\operatorname{col}(XH)=\operatorname{col}(X)$。由定义 1,$R^2_{\max}$ 只通过 $X$ 在 $\operatorname{col}(Z)$ 上的正交投影取值,而投影只依赖两个列空间;两个列空间均未改变,故值不变。主角定义为两个列空间正交基之积的奇异值,同理不变。∎

推论 1.1(跨模型可比性)

设两个独立训练的编码器在同一批输入上给出 $Z_A\in\mathbb R^{n\times d_A}$ 与 $Z_B\in\mathbb R^{n\times d_B}$,允许 $d_A\ne d_B$。只要 $k\le\min(d_A,d_B)$,主角余弦谱即定义良好,且比较无需任何对齐步骤。这与仅在正交群下不变、跨模型时须先作 Procrustes 对齐的量(余弦相似度、CKA、主成分能量占比)不同。

定理 2(观测决定系数的谱展开)

设 $Z=U\Sigma V^\top$ 为瘦奇异值分解,$\Sigma=\mathrm{diag}(\sigma_1,\dots,\sigma_r)$。岭回归目标为 $\min_W\|X-ZW\|_F^2+\lambda\|W\|_F^2$。则

$$\hat X_\lambda=U\,\mathrm{diag}(\tau_1,\dots,\tau_r)\,U^\top X,\qquad \tau_j=\frac{\sigma_j^2}{\sigma_j^2+\lambda},$$

残差按左奇异向量的列展开为

$$\|X-\hat X_\lambda\|_F^2\;=\;\sum_{j=1}^{r}(1-\tau_j)^2\|u_j^\top X\|_F^2\;+\;\sum_{j\gt r}\|u_j^\top X\|_F^2 ,$$

其中第二项与 $\lambda$ 及 $\{\sigma_j\}$ 无关。

证明。岭回归的闭式解为 $W^\star=(Z^\top Z+\lambda I)^{-1}Z^\top X$。代入 $Z=U\Sigma V^\top$ 得 $W^\star=V(\Sigma^2+\lambda I)^{-1}\Sigma U^\top X$,于是 $\hat X_\lambda=U\Sigma^2(\Sigma^2+\lambda I)^{-1}U^\top X=U\,\mathrm{diag}(\tau_j)\,U^\top X$。将 $X$ 按 $\{u_j\}_{j\le n}$ 展开并取差即得。∎

推论 2.1(误差的可加分解)

记 $X_\parallel$ 为 $X$ 在 $\operatorname{col}(Z)$ 上的投影、$X_\perp=X-X_\parallel$。则

$$\underbrace{\|X-\hat X_\lambda\|_F^2}_{\text{观测残差}}\;=\;\underbrace{\|X_\perp\|_F^2}_{\text{投影残差}}\;+\;\underbrace{\sum_{j=1}^{r}(1-\tau_j)^2\|u_j^\top X_\parallel\|_F^2}_{\text{收缩偏差}} .$$

投影残差只由 $\operatorname{col}(Z)$ 决定,对基不变(定理 1);收缩偏差只由 $\{\sigma_j\}$ 与 $\lambda$ 决定,可被重参数化任意改变。

推论 2.1 是本文的主要技术陈述。它把"逐层探针曲线"严格地分成两项:一项是子空间的性质,一项是估计量的性质。文献中报告的曲线是两项之和(经 $R^2$ 归一后为差),因此无法从曲线形状判断其来源。

关于特征标准化的说明

逐特征标准化(z-score)把各列方差归一到 1,其作用是缩小 $\{\sigma_j\}$ 的离散度,从而降低收缩偏差的散布。但它本身是一次重参数化,并不消除 $\Delta_\lambda$;而且在重参数化之后需要重新标准化。因此在报告中,标准化应被记为一项明确的处理,而非默认步骤。

定理 3(归因判据)

设逐层观测曲线 $R^2_\lambda(\ell)$ 与最佳可解码性 $R^2_{\max}(\ell)$ 均已测得。给定容差 $\delta\gt 0$,若

  1. $\max_\ell R^2_{\max}(\ell)-\min_\ell R^2_{\max}(\ell)\lt\delta$;且
  2. $\max_\ell R^2_\lambda(\ell)-\min_\ell R^2_\lambda(\ell)\gt\delta$,

则观测曲线的层间变异不能由最佳可解码性的变异解释,必归于正则化间隙 $\Delta_\lambda$。

证明。由定义 $\Delta_\lambda=R^2_{\max}-R^2_\lambda$,故 $R^2_\lambda=R^2_{\max}-\Delta_\lambda$。若 $R^2_{\max}$ 的极差小于 $\delta$,则 $R^2_\lambda$ 的极差大于 $\delta$ 只能由 $\Delta_\lambda$ 贡献。∎

容差 δ 的确定

$\delta$ 不能由主张设定,须由数据估计。做法:同一骨干、同一层、同一数据,以 3 个训练种子重跑探针,计算 $R^2_{\max}$ 在各层上的跨种子标准差,取 $\delta=2\hat\sigma$。若不报告 $\delta$ 与其估计方式,定理 3 的条件 1 无法被读者检验,判据即失去效力。

4判别性检验

4.1 设计原则 检验的目标是判定 §3 的分解是否具有经验意义,即:逐层观测曲线的峰是否主要由正则化间隙贡献。为使结论不被"探针未充分训练"或"数据量不足"解释,设计须满足三项约束。

  1. 特征固定。一次前向缓存全部层的特征,此后不再调用模型。任何差异只能来自测量方式。
  2. 一项测量不含训练。$R^2_{\max}$ 由奇异值分解与正交投影给出,无需优化。这排除了"训练不足"这一类替代解释。
  3. 干预同时作用于两项。对 $Z$ 施加同一个随机可逆变换 $G$,重复两项测量。若第一项不变而第二项移动,归因即成立(定理 1 与定理 2 的直接推论)。

4.3两种可能的结果

4.4为何该检验成本低

以往判断同类问题需要枚举协议空间(骨干 × 探针族 × 参数化 × 指标 × 阈值 × 种子),因为该空间是无限的。本文的做法不枚举,而是利用定理 1:最佳可解码性只依赖列空间,任何重参数化都不改变它。因此只需测量一次,再用一次随机可逆变换验证其不变性。成本由"枚举"降为"验证",这是该设计经济性的全部来源。

前提

该检验要求目标因子可观测。这在合成数据集(dSprites、3D Shapes)与带深度标注的真实数据集(NYU Depth v2)上成立;在无标注自然图像上不成立。对后者,一种替代是把 $X$ 换为另一模型的输出,但此时测量的是模型间差异,不再是表征与外部变量之间的对齐,本文不主张二者等价。

5.2$\delta$ 的定义

P2 中的 $\delta$ 须由数据确定,定义如下:

$$\delta\;=\;2\cdot\overline{\operatorname{sd}_{\text{seed}}}\Big[R^2_{\max}(\ell)\Big]_{\ell=1}^{L} ,$$

即每个层上由 3 个训练种子引起的标准差,在层上平均后取两倍。于是"平坦"的精确含义为

$$\max_\ell R^2_{\max}(\ell)\;-\;\min_\ell R^2_{\max}(\ell)\;\lt\;\delta .$$

该定义可被检验:若 $\delta$ 大到使任意曲线都满足上式,P1 与 P2 即失效。因此报告中须同时给出 $\delta$ 与 $R^2_{\max}$ 的跨层极差,由读者判断该比值是否有说服力。

5.3三项拒绝条件

条件 A:P2 被拒绝

若 $R^2_{\max}$ 在随机可逆变换下明显移动,说明定理 1 的推导与实现不符。最可能的原因是计算流程中对特征做了逐维归一化,从而在投影之前重新引入了依赖 $G$ 的缩放。这是本文最可能在实现层面出错的地方,应先排查实现,再考虑修改主张。

条件 B:P3 被拒绝

若在随机 $G$ 下 $R^2_\lambda$ 曲线完全不动,则收缩偏差在实践中可忽略;定理 2 仍为真但无经验意义,本文关于"峰归于正则化间隙"的主张被推翻。

条件 C:P1 与 P2 同时被拒绝,且 $R^2_{\max}$ 的峰在 $G$ 下不变

若最佳可解码性自身存在跨层峰,且该峰对重参数化不敏感,则峰归于内容差异。此情形推翻本文的分解框架,但同时为"按层选择"提供了此前的文献未曾给出的正面证据。

5.4若预测成立,对实践的含义

两点,均为工程层面的推论:

  • 全层扫描可被单层测量取代。若 $R^2_{\max}$ 跨层平坦,则任取一层,在充分校准的读出下可得相同的可解码性;逐层扫描不再是必要条件。
  • 需要校准的是读出强度,而非层号。待标定的量为 $\lambda$ 与标准化方式,属二维连续搜索;层号属离散搜索。前者的成本低于后者,且可跨模型迁移。

需要说明的是,这两点推论依赖 P1–P3 全部成立;本文未做测量,故其为条件性推论,不宜作为结论陈述。

6.2局限

其一,需要可观测的目标因子。$R^2_{\max}$ 的定义要求 $X$ 已知。这在合成数据与带深度标注的数据集上成立,在无标注自然图像上不成立。将 $X$ 替换为另一模型的输出会使命题从"表征与外变量的对齐"变为"模型间的一致性",两者不可混用。

其二,线性子空间是一个强简化。目标因子可能以非线性方式编码。本文的量只刻画线性可及的部分;若存在非线性编码的内容,$R^2_{\max}$ 会低估之。因此"平坦"不应被读作"不存在非线性内容",而应读作"线性可及的内容在层间变化小"。

其三,样本单位的选取影响可执行性。如 §2.1 所述,整图级特征在 $n\lt d$ 时使 $R^2_{\max}\equiv1$,分解退化。本文的分析要求 token 级特征,这限制了可用于分析的数据集类型(需要逐 token 的因子标注)。

其四,单骨干、单数据集。§4 的设计只覆盖一个骨干。跨骨干推广在数学上由推论 1.1 支持,但实践中需处理 $d$ 不同与 token 数不一致的问题,后者不是本文解决问题。

6.3一个可由已有数据检验的推论

若 $R^2_{\max}$ 跨层平坦,则任何报告的峰高应随读出容量上升而饱和:容量增加会减少收缩偏差,从而削减峰高。该推论可用已发表论文中的表格检验——只要那些论文报告了同一骨干、多个读出容量下的峰高。此检验不需新实验,本文未做。

7结论

逐层线性探针报告的曲线被普遍解读为"几何信息随深度的分布"。本文指出该曲线是两项之差:一项是子空间的性质(最佳线性可解码性),另一项是估计量的性质(正则化间隙)。前者对特征与因子两侧的可逆线性变换均不变(定理 1),后者不是(定理 2),二者可加而互不干扰(推论 2.1)。当第一项跨层平坦而第二项存在结构时,观测到的峰只能归于后者(定理 3)。

这一分解不依赖新实验即可成立;其经验意义则依赖 §5 的预测是否被接受。检验的成本被压缩到数小时,原因是它不枚举协议空间,而是验证一条不变性。

需要强调本文不主张的范围:其一,本文不主张逐层探针无用;其二,本文不主张层间无差异;其三,本文未做任何测量。本文主张的是,在报告一条逐层可解码性曲线时,应同时报告其最佳可解码性,或等价地报告主角谱——后者与被报告的曲线之差,即为正则化间隙,其大小可由读者判断。

A附录

A.1秩亏情形

若 $\operatorname{rank}Z=r\lt d$,则 $Z$ 的右零空间非平凡,权重 $W$ 在该方向上的分量不可辨识。但 $\operatorname{col}(ZG)=\operatorname{col}(Z)$ 对可逆 $G$ 仍成立,$R^2_{\max}$ 与主角谱的定义不变,可比较的方向数上限由 $\min(k,d)$ 降为 $\min(k,r)$。若 $r\lt k$,必有部分因子方向无法被覆盖,此非测量问题而是特征维数不足,应在报告时说明。

若 $X$ 秩亏,同理可把 $\operatorname{col}(X)$ 的维数取为 $\operatorname{rank}X$。

A.2定理 2 的完整推导

岭回归目标 $\min_W\|X-ZW\|_F^2+\lambda\|W\|_F^2$ 的解为

$$W^\star=(Z^\top Z+\lambda I)^{-1}Z^\top X .$$

取 $Z=U\Sigma V^\top$(瘦分解,$U\in\mathbb R^{n\times r}$,$\Sigma\in\mathbb R^{r\times r}$,$V\in\mathbb R^{d\times r}$),则 $Z^\top Z=V\Sigma^2V^\top$,故

$$W^\star=V(\Sigma^2+\lambda I)^{-1}\Sigma U^\top X,\qquad \hat X_\lambda=ZW^\star=U\Sigma^2(\Sigma^2+\lambda I)^{-1}U^\top X .$$

令 $P_\lambda=U\,\mathrm{diag}(\tau_1,\dots,\tau_r)\,U^\top$,$\tau_j=\sigma_j^2/(\sigma_j^2+\lambda)$,则 $\hat X_\lambda=P_\lambda X$。残差按 $U$ 的完备列展开:

$$\|X-\hat X_\lambda\|_F^2=\sum_{j=1}^{r}(1-\tau_j)^2\|u_j^\top X\|_F^2+\sum_{j\gt r}\|u_j^\top X\|_F^2 .$$

第一项是收缩偏差;第二项是投影残差,与 $\lambda$ 及 $\{\sigma_j\}$ 无关。由于 $u_j$ 是 $\operatorname{col}(Z)$ 的正交基,第二项等于 $\|X_\perp\|_F^2$,推论 2.1 得证。

A.3主角余弦谱的计算

不应显式构造完整正交基。用薄奇异值分解一次完成:

PYTHON · principal_angles 可运行 
import numpy as np

def principal_cosines(Z, X, tol=1e-10):
    """Z: (n,d) features; X: (n,k) factors.
    Returns cos(theta_i), i = 1..min(k, rank Z), descending."""
    QZ, sZ, _ = np.linalg.svd(Z, full_matrices=False)
    r = int((sZ > tol * sZ[0]).sum())
    QX, sX, _ = np.linalg.svd(X, full_matrices=False)
    k = int((sX > tol * sX[0]).sum())
    s = np.linalg.svd(QX[:, :k].T @ QZ[:, :r], compute_uv=False)
    return np.clip(s[:min(k, r)], 0.0, 1.0)

# invariance check: should be at machine precision
def invariance_residual(Z, X, n_trials=10, seed=0):
    rng = np.random.default_rng(seed)
    base = principal_cosines(Z, X)
    d = Z.shape[1]
    worst = 0.0
    for _ in range(n_trials):
        G = rng.standard_normal((d, d))
        if np.linalg.cond(G) > 1e3:
            continue
        worst = max(worst, np.abs(principal_cosines(Z @ G, X) - base).max())
    return worst

invariance_residual 的返回值应在机器精度量级(约 $10^{-14}$)。若显著大于零,首先应检查计算流程中是否在投影之前对 $Z$ 做了逐维归一化。

A.4复现要点

  • 缓存:一次前向,保存所有层的 token 级特征;若同时需要整图特征,另行池化,并注意 §2.1 的 $n$ 与 $d$ 关系。
  • 因子:$X$ 按列中心化;不预先标准化 $Z$,除非作为单独的处理条件。
  • 主角:用奇异值分解求正交基,不用 Gram 矩阵特征分解(条件数平方会放大误差)。
  • 岭回归:固定数据划分、固定 $\lambda$、3 个种子;报告均值与种子标准差。
  • 干预:随机 $G$ 使用固定种子,条件数限制在 $10^3$ 以内,超限则重采样。
  • 报告:四项同图($R^2_{\max}$、$R^2_{\max}\circ G$、$R^2_\lambda$、$R^2_\lambda\circ G$),并给出 $\delta$ 及其估计方式。
