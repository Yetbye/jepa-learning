# 逐层线性可解码性的分解:子空间对齐与正则化间隙

中文草稿。主张:逐层线性探针报告的曲线是两个性质不同的量之差,前者对重参数化不变,后者不是。

## 术语表(全部为领域标准用法)

| 术语 | 含义 | 出处 |
|---|---|---|
| 最佳线性可解码性 R²max | 无正则、总体最优意义下的线性可决系数 | 本文定义 1 |
| 正则化间隙 Δλ | R²max − R²λ,收缩造成的精度损失 | 本文定义 3 |
| 主角 (principal angles) | 两个子空间之间的夹角 | Golub & Van Loan §6.4.3 |
| 投影残差 / 收缩偏差 | 推论 2.1 的两项 | 本文 |
| 岭回归 shrinkage τ=σ²/(σ²+λ) | 标准谱展开 | Hoerl & Kennard 1970 |

**全文不使用自造术语。** 此前的版本用过"内容/度量/坐标""峰是尺子画的"等表述,已废弃。

## 三项结果

- **定理 1**:R²max 与主角余弦谱对 Z→ZG、X→XH 均不变。
  - 推论 1.1:因此跨模型比较无需 Procrustes 对齐。
- **定理 2**:R²λ = R²max − Δλ,Δλ 有精确谱展开,只依赖 {σj} 与 λ。
- **定理 3**:若 R²max 跨层平坦而 R²λ 有峰,则峰必归于 Δλ(需报告 δ)。

## 判别性检验

一次缓存、一次 SVD、13 次岭回归,数小时。四线同图:R²max、R²max∘G、R²λ、R²λ∘G。

- 前者不动、后者移动 → 峰归于正则化间隙
- 前者自身有峰且对 G 不变 → 峰归于内容差异,框架不适用

## 与 arXiv:2610.22655 的关系

该文指出线性探针过宽,提三项诊断:反向预测性、谱集中度、分布外泛化。
其中**谱集中度(前 m 个主成分能量占比)在同一子空间的基旋转下会变**,是其诊断中唯一不具参数化稳健性的一个。
本文的主角谱可替代它:同样区分"线性子空间"与"弯曲流形",但对基不变。
