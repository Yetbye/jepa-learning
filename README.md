## 论文:核心主张

逐层线性探针报告的可解码性曲线,是两个性质不同的量之差:

| 量 | 定义 | 对特征重参数化 $Z\mapsto ZG$ |
|---|---|---|
| **最佳线性可解码性** $R^2_{\max}$ | 无正则、总体最优的线性可决系数,等于目标因子子空间与特征子空间主角的加权和 | **不变**(定理 1) |
| **正则化间隙** $\Delta_\lambda$ | $R^2_{\max}-R^2_\lambda$,收缩造成的精度损失,有精确谱展开 $\sum_j(1-\tau_j)^2\|u_j^\top X\|^2$ | **改变**(定理 2) |

**推论 2.1**:总残差 = 投影残差 + 收缩偏差,两项可加且互不干扰。

**定理 3**:若 $R^2_{\max}$ 跨层平坦而观测曲线有峰,则峰必归于 $\Delta_\lambda$。

### 判别性检验

单骨干、单数据集、一次特征缓存、一次 SVD、13 次岭回归,**数小时**。

四线同图:$R^2_{\max}$、$R^2_{\max}\!\circ G$、$R^2_\lambda$、$R^2_\lambda\!\circ G$。

- 前者平坦且不动、后者有峰且移动 → 峰归于正则化间隙
- 前者自身有峰且不动 → 峰归于内容差异,框架不适用(该结果同时为层选择提供正面证据)

成本之所以低:不枚举无限协议空间,只验证一条不变性。

### 与 arXiv:2610.22655 的接口

该文指出线性探针过宽,提三项诊断:反向预测性、**谱集中度**、分布外泛化。

其中谱集中度(前 $m$ 个主成分的能量占比)在同一子空间的基旋转下会变——它依赖参数化。本文的主角谱可替代:同样区分"线性子空间"与"弯曲流形",但对基不变。
