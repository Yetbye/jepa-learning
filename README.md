## 论文:核心主张

在四个自监督骨干(DINOv2-B/L、DINOv3-B/L)上测量层可解码性,得到两条结论与一条负结果:

**① 形状一致。** 训练集上界 R²(max) 在相对深度约 **0.67** 处进入平台,此后不再上升;held-out 分数紧随其后,峰在平台起点之后 0–5 层。四个骨干的绝对分数不同(0.146–0.161),但转折位置相近。

**② 平台内的层序不可复现。** 全层口径的跨划分 Kendall τ 是 0.72–0.76,看起来"层序稳定";但限制在平台内部时(有 ≥5 层的三个骨干),τ 掉到 **−0.19 至 +0.07**,置换检验 p = 0.28–0.93,与完全随机相容。全层的 τ 来自"浅层 < 深层"的单调台阶,不能外推到平台内部。

**③ 一条被否证的候选定律。** 曾假设层序稳定性由单一分离度变量决定。它在两个 13 层骨干上拟合极好(R²=0.98),在 25 层骨干上失效,留出预测 skill 仅 **0.32**。本文把这条失败写进正文,而不是留在实验记录里。

### 为什么这值得写

"取第 12 层"这句话包含一个比较。本文测量的是:这个比较发生在剖面的哪一段,以及那一段上的排序能否被另一批数据复现。答案是——发生在相对深度 0.67 之后的那一段,而那里不可复现。
