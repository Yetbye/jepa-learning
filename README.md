## 论文:核心主张

在四个自监督骨干(DINOv2-B/L、DINOv3-B/L)上,把"训练集可解码性上界"与"held-out 分数"分开测量,得到一条二分:

**① 封顶位置。** 线性可解码性在**相对深度 0.67** 达到最优值的 90%。三个骨干精确重合(0.67),第四个因层数最少落在 0.83。绝对上界随骨干不同(0.146–0.161),相对位置不变。

**② 排序信息只在封顶之前。** 全层层序的跨划分 Kendall τ 是 0.72–0.76,**封顶之后掉到 −0.19 至 +0.11**,4000 次置换的零假设区间完整覆盖观测值。全层的 τ 来自"浅层 < 深层"的单调台阶,不能支持平台内的层间比较。

**③ 机制。** 训练集分数有精确闭式 Σ_j τ_j(2−τ_j)w_j,上界 R²(max)=Σ_j w_j 与正则无关、只由子空间对齐决定。层间排序信号正比于对齐能量的增量,平台内该增量为零。

**④ 边界。** 一个把 τ 写成单一分离度标量的候选规律在 13 层骨干上成立(R²=0.98),在 25 层骨干上不成立(预报技巧 0.32)。这说明平台内的可复现性依赖模型规模,不能用单一标量概括。

### 一句话

**探针层选择的前半段是信号,后半段是噪声。** 把封顶位置与两个口径的 τ 一起报,读者就知道一个层选择结论落在哪一边。
