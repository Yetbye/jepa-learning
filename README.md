## 这篇课要回答什么

一个机器人在"脑子里"想象未来、挑选动作序列的时候,为什么它挑中的往往是**模型最不懂**的那一个?

答案可以浓缩成一个恒等式:

```
C*(â) = C(â)  +  Δ(â)
         ↑        ↑
    优化器压到底   优化器选出来的
```

优化器只看得见 `C`(模型自己给的代价),看不见 `Δ`(模型错多少)。而如果 `Cov(C, Δ) < 0`——模型代价越低的地方错得越多——那么 argmin 就是一个**专门挑选模型盲区**的机器。

## 三个核心公式

**① 曲率分解**(第 6 章)——非凸性只来自残差项:

```
∇²C(a) = 2 JᵀJ + 2 Σₖ (Fₖ(a) − z_g,ₖ) ∇²Fₖ(a)
         └─半正定─┘   └──────可正可负──────┘
```

**② 条件期望**(第 9 章)——模型越自信越错的数学形式:

```
E[Δ | C = c] = μ_Δ + ρ · (σ_Δ/σ_C) · (c − μ_C)
```

**③ 选择偏差**(第 10 章)——选得越狠,错得越多:

```
E[Δ | selected] ≈ μ_Δ − ρ σ_Δ √(2 ln k)
```
